# 전자결재 시스템 권한 없음 오류 조치

## 1. 주요 증상
전자결재 문서 작성 시 특정 결재 메뉴에 대한 접근 거부 팝업이 발생하는 현상입니다.

## 2. 원인 분석
직무 변경 또는 보직 이동 직후 결재 전용 권한 데이터가 그룹웨어 정보와 실시간 연동되지 않아 발생합니다.

## 3. 조치 절차
### 단계 1
결재 시스템 상단의 마이페이지 메뉴를 누릅니다.
### 단계 2
개인 직무 프로필 세부 사항 및 결재 등급을 갱신합니다.
### 단계 3
[업무 시스템 관리자 화면]의 직급 가이드라인에 맞춰 자동 권한 갱신을 클릭합니다.
### 단계 4
정상 반영 확인을 위해 브라우저 재시작 후 기안 문서를 작성합니다.
