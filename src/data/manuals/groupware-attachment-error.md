# 그룹웨어 대용량 첨부파일 업로드 실패 조치

## 1. 주요 증상
메일 작성 시 50MB 이상의 첨부파일 전송이 중단되며 대용량 업로드 에러가 납니다.

## 2. 원인 분석
브라우저 실시간 전송 모듈 플러그인이 비정상 정지되거나 네트워크 지연이 일어납니다.

## 3. 조치 절차
### 단계 1
브라우저 환경설정에서 보안 모듈 실행 권한을 확인합니다.
### 단계 2
[업무 시스템 관리자 화면]의 첨부 전용 도구 플러그인을 수동 재설치합니다.
### 단계 3
차선책으로 대용량 파일을 [익명화된 사내 포털 시스템] 공유 클라우드 주소로 전송합니다.
### 단계 4
해당 임시 공유 링크 주소를 메일 본문에 붙여 넣어 전달합니다.
