# 사내 인터넷 IP 전화기 부팅 실패 및 불통 오류 해결

## 1. 주요 증상
전화기 액정 화면에 부팅 오류가 흐르며 수발신이 되지 않고 먹통으로 유지됩니다.

## 2. 원인 분석
네트워크 공급 포트의 PoE 전력 결상 및 IP 수동 충돌이 원인입니다.

## 3. 조치 절차
### 단계 1
전화기 뒷면의 LAN 선을 분리 후 10초 대기하였다가 다시 딸칵 소리가 나도록 결합합니다.
### 단계 2
전화기 다이얼 메뉴에서 네트워크 DHCP 자동 설정 상태를 점검합니다.
### 단계 3
[업무 시스템 관리자 화면]의 기기 내선 번호와 MAC 매핑 설정 일치 여부를 조회합니다.
### 단계 4
IP 재할당이 완료되고 대기 화면에 정상적으로 번호가 기재되는지 확인합니다.
