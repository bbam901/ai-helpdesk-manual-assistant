# 사내 Wi-Fi 연결 끊김 및 IP 주소 충돌 해결 가이드

## 1. 주요 증상
노트북으로 사내 Wi-Fi 접속 시 IP 할당 대기 상태로 지연되며 인터넷이 끊기는 장애입니다.

## 2. 원인 분석
동일 게이트웨이 영역 내에 고정 IP를 할당하여 무단 사용하는 기기가 존재할 때 나타납니다.

## 3. 조치 절차
### 단계 1
제어판 네트워크 어댑터 속성에서 IPv4 설정에 들어갑니다.
### 단계 2
고정 IP 설정을 IP 주소 자동으로 받기 모드로 변경합니다.
### 단계 3
[익명화된 사내 포털 시스템]에 접속하여 임시 IP 충돌 예방 주소를 받아 적용합니다.
### 단계 4
cmd 창에서 ipconfig /renew 명령어를 실행하여 새로운 동적 IP를 할당받습니다.
