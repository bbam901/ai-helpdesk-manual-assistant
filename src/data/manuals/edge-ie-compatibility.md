# 엣지 브라우저 액티브X 및 IE 호환성 오류 해결

## 1. 주요 증상
특정 인사 평가 조회 사이트 등 레거시 화면이 로딩되지 않거나 먹통으로 멈추는 장애입니다.

## 2. 원인 분석
액티브X 또는 오래된 플러그인이 필요한 구버전 웹 호환 기술을 필요로 하여 정상 브라우징이 제한되기 때문입니다.

## 3. 조치 절차
### 단계 1
엣지 브라우저 우측 상단 더보기 옵션에서 설정을 실행합니다.
### 단계 2
기본 브라우저 탭에서 Internet Explorer 호환 모드 허용 단추를 선택합니다.
### 단계 3
해당 레거시 사이트 URL을 [익명화된 사내 포털 시스템] 가이드 양식에 맞게 복사해 추가합니다.
### 단계 4
해당 사이트로 다시 진입하여 상단에 IE 모드 단추가 정상 노출되는지 점검합니다.
