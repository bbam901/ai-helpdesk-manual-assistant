# 사외 VPN 보안 연결 실패 원인 및 해결 조치

## 1. 주요 증상
사외에서 VPN 로그인 시 연동 오류로 시스템 진입이 차단됩니다.

## 2. 원인 분석
보안 인증 2차 OTP 데이터 불일치 및 가상 드라이버의 IP 충돌이 원인입니다.

## 3. 조치 절차
### 단계 1
VPN 클라이언트의 설정 파일 정보가 적절한지 다시 대조합니다.
### 단계 2
[익명화된 사내 포털 시스템] 모바일 기기 OTP 초기화 서비스 페이지에 접속합니다.
### 단계 3
보안 가상 네트워크 어댑터 진단 갱신 옵션을 클릭합니다.
### 단계 4
모바일 앱으로 전송받은 새 토큰 코드를 인증서 서브 입력창에 입력합니다.
