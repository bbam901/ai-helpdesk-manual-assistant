# 네트워크 프린터 인쇄 대기열 및 스풀러 오류 조치

## 1. 주요 증상
인쇄 버튼을 눌러도 프린트 출력이 되지 않고 문서가 대기열에 계속 남아있습니다.

## 2. 원인 분석
PC 내부의 스풀러 서비스 엔진에 대량 일시 정지가 걸렸을 때 발생합니다.

## 3. 조치 절차
### 단계 1
윈도우 제어판 서비스 관리 프로그램에서 Print Spooler를 중지합니다.
### 단계 2
윈도우 탐색기에서 [익명화된 시스템 주소]의 spool/PRINTERS 폴더 임시 파일을 제거합니다.
### 단계 3
다시 서비스 관리 창에서 Print Spooler를 시작 모드로 변경합니다.
### 단계 4
출력 오류 문서를 삭제한 다음 인쇄를 재시도합니다.

## 4. 관련 부서 및 문의처
