# 통합 포털 패스워드 5회 오류 해제 매뉴얼

## 1. 주요 증상
포털 시스템 로그인 시 패스워드 연속 불일치로 계정이 비활성화되는 현상입니다.

## 2. 원인 분석
패스워드를 연속 5회 잘못 입력할 시 계정 해킹을 방지하고자 2차 인증 전까지 로그인이 전면 금지됩니다.

## 3. 조치 절차
### 단계 1
모바일 사내 앱의 통합 인증 센터 서비스 페이지에 들어갑니다.
### 단계 2
사번과 이름 입력 후 모바일 SMS 실명 인증을 요청합니다.
### 단계 3
전송받은 OTP 임시 해제 번호를 입력창에 주입합니다.
### 단계 4
신규 패스워드 규정에 맞춰 암호를 변경하고 포털에 접속합니다.
