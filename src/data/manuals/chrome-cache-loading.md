# 크롬 브라우저 캐시 및 사내 시스템 로딩 지연 해결 가이드

## 1. 주요 증상
크롬 브라우저로 ERP 등 사내 시스템 화면을 열었을 때 먹통 현상이나 CSS 깨짐이 나타납니다.

## 2. 원인 분석
이전 패치 버전의 정적 파일 캐시가 새로운 시스템 코드 버전과 충돌을 빚는 원인입니다.

## 3. 조치 절차
### 단계 1
크롬 브라우저 우측 상단 더보기 옵션에서 도구 더보기 인터넷 사용 기록 삭제를 선택합니다.
### 단계 2
기간 설정을 전체 기간으로 셋업하고 쿠키 및 캐시 이미지 옵션에 체크합니다.
### 단계 3
기록 삭제 단추를 클릭해 로컬 디스크 내의 오래된 캐시 데이터를 소거합니다.
### 단계 4
ERP 주소 입력창에서 Ctrl + F5를 입력해 강제 무캐시 리로드 상태로 화면을 로딩합니다.
