# 회의실 빔프로젝터 화면 무신호 및 출력 오류 해결 가이드

## 1. 주요 증상
회의실 빔프로젝터 가동 시 천장 프로젝터 투사면에 무신호 메시지가 발생합니다.

## 2. 원인 분석
노트북 화면 복제 비디오 드라이버와 벽면 HDMI 연장 케이블 모듈 간 신호 호환 결함입니다.

## 3. 조치 절차
### 단계 1
벽면 HDMI 케이블을 뽑았다가 금속 접촉면 세척 후 재장착합니다.
### 단계 2
노트북에서 Window 키 + P를 동시에 입력하여 복제 모드로 전환합니다.
### 단계 3
노트북 비디오 그래픽 설정에서 출력 재생 빈도를 60Hz로 고정 설정합니다.
### 단계 4
신호 변환 젠더를 분리하고 프로젝터 입력 소스를 HDMI1으로 전환합니다.
