# ERP 계정 잠금 및 로그인 실패 조치 가이드

## 1. 주요 증상
ERP 로그인 시 계정 잠금 메시지가 표시되며 접속이 되지 않는 현상입니다.

## 2. 원인 분석
보안 정책상 비밀번호 5회 이상 오입력 시 계정이 자동 잠금 상태로 전환됩니다.

## 3. 조치 절차
### 단계 1
[익명화된 사내 포털 시스템]의 비밀번호 해제 페이지에 접속합니다.
### 단계 2
사내 메신저 일회용 OTP 인증을 진행합니다.
### 단계 3
계정 상태 확인 후 잠금 해제 단추를 누릅니다.
### 단계 4
3분 후 새로운 패스워드로 재접속을 테스트합니다.
