# 프로젝트 공유 드라이브 액세스 거부 조치 가이드

## 1. 주요 증상
네트워크 공유 폴더 접근 시 지정된 권한이 없어 공유 드라이브 폴더가 열리지 않는 현상입니다.

## 2. 원인 분석
해당 공유 드라이브의 사용자 접근 제어 관리 명단에 현재 본인의 계정 그룹이 등록되어 있지 않은 경우입니다.

## 3. 조치 절차
### 단계 1
[익명화된 사내 포털 시스템]의 IT 서비스 신청 코너를 엽니다.
### 단계 2
권한 신청 메뉴에서 타겟 네트워크 공유 드라이브 경로를 기입합니다.
### 단계 3
본인 부서장의 결재 선을 지정하여 승인 요청 프로세스를 진행합니다.
### 단계 4
최종 결재가 끝난 뒤 PC를 재부팅하고 다시 공유 폴더에 접속합니다.
