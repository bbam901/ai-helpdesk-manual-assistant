# 사내 OTP 인증 번호 불일치 및 시간 동기화 해결 매뉴얼

## 1. 주요 증상
업무 시스템 2차 로그인 시 OTP 기기에 적힌 숫자를 입력했으나 인증 실패 경고가 발생합니다.

## 2. 원인 분석
OTP 생성 장치의 자체 하드웨어 시계와 인증 검증 서버의 글로벌 표준 시계가 미세하게 맞지 않을 때 생깁니다.

## 3. 조치 절차
### 단계 1
모바일 스마트 OTP 앱 환경설정에 진입합니다.
### 단계 2
시간 정보 동기화 단추를 눌러 스마트폰 서버 시간과 일치하도록 맞춥니다.
### 단계 3
동기화 지연 시 [익명화된 사내 포털 시스템]에 접속하여 OTP 일련번호 재등록을 요청합니다.
### 단계 4
OTP 앱 재생성을 실행하고 표시된 신규 일회용 암호를 재입력합니다.
