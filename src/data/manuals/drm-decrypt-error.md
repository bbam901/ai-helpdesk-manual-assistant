# 문서 보안 DRM 파일 해제 및 반출 실패 해결 가이드

## 1. 주요 증상
외부 협력사로 전송할 마이크로소프트 엑셀 문서의 DRM 보안 암호화 해제가 실패하는 에러입니다.

## 2. 원인 분석
해당 파일이 보안 그룹 정책에 의해 외부 유출 방지 지정 파일로 귀속되어 해제 신청 조건이 기각되었기 때문입니다.

## 3. 조치 절차
### 단계 1
보안 에이전트의 문서 세부 속성에서 DRM 락 등급을 확인합니다.
### 단계 2
[익명화된 사내 포털 시스템]에 접속해 외부 반출 승인 요청서를 기재합니다.
### 단계 3
결재 권한자의 반출 목적 승인을 획득합니다.
### 단계 4
보안 전용 반출 단추를 클릭해 암호화가 영구 해제된 문서를 받아 전송합니다.
